# 분석 방법과 재검증 범위

## 연구 인턴과 후속 분석

2026년 1월 POSTECH IME 연구실 인턴에서 논문의 공분산 추정·분해·예측 절차를 구현하고 검토했습니다. 이 저장소의 현재 결과표와 점프 처리 비교는 **2026년 10월 기존 프로젝트를 다시 실행한 후속 분석**입니다. 후속 결과를 인턴 당시의 성과로 소급하지 않습니다.

## 데이터와 평가

- 200개 종목, 2016~2019년 997거래일, 1분 로그가격.
- 2018~2019년 실제 거래일 497일을 평가합니다. 임의로 만든 영업일 인덱스를 사용하지 않습니다.
- 각 평가일의 학습에는 직전 251일만 사용합니다. 점프 예측에는 전날 추정치를 사용합니다.
- 시초에 정한 투자 비중을 하루 동안 유지하고, 39개 10분 수익률의 가중합 제곱을 더해 일별 실현분산을 구합니다.
- 연율화 위험은 `sqrt(250 * mean(daily_realized_variance)) * 100`입니다.
- 총 투자 비중은 1, 절대 비중 합은 1.0부터 3.0까지 0.2 간격으로 제한합니다.

원자료는 09:30~15:59의 390개 가격입니다. 16:00 가격 대신 15:59 가격을 이어 써 마지막 구간은 관측상 9분입니다. 익일 시가를 당일 수익률에 섞지 않았습니다.

## 추정과 예측

PRVM은 Appendix A.2의 명시된 식을 사용합니다. `K=19`, `psi=1/12`, bipower 기반 점프 임계값의 `c0=4`, `alpha_u=0.47`입니다. 본문 실증분석의 sample-SD 계수 설명과 A.2의 연결이 불명확하므로 본문과 같은 임계값이라고 단정하지 않습니다.

날짜별 PCA로 공통 성분을 제거한 후 산업 내 공분산만 남깁니다. 최근 22일 평균에서 얻은 공통·개별 고유벡터는 각 251일 학습 창 안에서 고정합니다.

| 항목 | 설정 |
|---|---|
| 학습 기간 / 고유벡터 추정 기간 | 251일 / 22일 |
| 공통 요인 수 / 시차 | 3 / 1 |
| 공통 성분 튜닝 상수 | 4, 0.25 |
| 개별 성분 튜닝 상수 | 4, 4 |
| 규제 강도 후보 | `c_eta` 0.1~10, 로그 간격 21개 |
| 선택 기준 | 응답별 `N * log(MSE) + df * log(N)` |

위 기간·상수·요인 수·시차는 논문에 보고된 선택값을 재사용했습니다. 2017년 전체 격자 탐색을 다시 수행하지 않았습니다. BIC의 식, 후보 간격과 응답별 선택 여부는 논문에 자세히 명시되지 않아 구현상 선택한 부분입니다. 회귀계수 자체는 매 학습 창에서 다시 추정합니다.

공통 성분은 RMS 스케일을, 개별 성분은 열별 평균과 표준편차를 사용합니다. 회귀의 상수항은 유지하며 개별 성분의 L1 벌점에는 상수항도 포함합니다. Huber-LASSO는 수렴 후 KKT 잔차가 `2e-5` 이하인지 점검합니다. 실제 실행의 최대 잔차는 약 `1.4e-5`였습니다.

## 점프 처리 비교

연속 공분산 예측을 `C`, 전날의 점프 추정을 `J`라고 할 때 다음을 비교했습니다.

1. 합산 후 보정: `PSD(C + J)`
2. 점프를 먼저 보정: `C + PSD(J)`
3. 점프 제외: `C`

`J`는 비절단 PRVM에서 절단 PRVM을 뺀 값으로, PSD 투영 전 추정량의 차이입니다. 497일 모두 `J`와 `C + J`에 음수 고유값이 있었습니다. 합산 후 보정에서는 평균 약 6.55개 방향의 고유값이 `1e-10`보다 작아졌습니다. 이처럼 과소평가된 위험 방향에 투자 비중이 배분될 수 있다는 점을 보정 순서의 민감도 분석으로 확인했습니다.

같은 예측 행렬에서 보정 방식만 바꿨을 때 H-LASSO의 위험은 10.6331%에서 8.0498%로 변했습니다. 점프 제외 결과는 8.1094%, 같은 별도 보정을 적용한 POET는 8.7153%였습니다. 이전 실행과 재계산한 기준 결과의 최대 일별 분산 절대 차이는 약 `5.9e-11`로, 회귀 재추정의 수치 차이는 작았습니다.

이는 평가기간을 이미 관찰한 뒤 수행한 진단입니다. 독립적인 신규 테스트 성과나 수익률 개선으로 해석하지 않습니다. 별도 PSD 보정이 원 저자 코드와 동일한지는 확인되지 않았습니다.

## 남은 차이

H-LASSO의 MSPE는 논문과 가까웠지만, 3일의 연속 공분산 예측에서 음수 고유값 보정이 필요했습니다. `1e-12` 바닥값으로 보정한 작은 고유값은 역행렬을 사용하는 QLIKE에 큰 영향을 주었습니다. 점프 처리 변경은 이 연속 공분산 예측 문제를 해결하지 않습니다. 해당 오차도 결과표에 그대로 남겼습니다.

논문 Figure 5의 7.9%와 8.6%는 그래프 근삿값입니다. 연 250거래일은 제공된 평가 노트북의 설정이며, 논문 본문에는 연율화 상수가 명확하지 않습니다. DCC-NL, HAR-DRD 등 논문의 모든 비교모형을 구현한 것은 아닙니다.

## 공개 범위

코드, 집계 결과표, 종목을 식별하지 않는 진단 통계와 그래프만 포함합니다. 원자료, 산업분류 원본, 제공 reference/solution, 종목별 중간 행렬은 공개하지 않습니다.
